# Jobscout Ranking Rubric

Only **verified** listings are scored. A listing that violates any strict must-have filter is
excluded **before** scoring and does not appear in the ranked results. This includes internships
when the profile excludes them, and a hard company-stage requirement (e.g. "startups only") when
the user set one. There is no fixed cap on the number of ranked results — score and rank every
verified listing that passes the filters.

Each verified listing is scored out of 100:

| Dimension | Points | Evaluation |
| --- | ---: | --- |
| Role and skills match | 40 | Target-title alignment and evidence of the core required skills in the listing. |
| Location and eligibility | 25 | Location, remote policy, work authorization, sponsorship, and relocation fit. |
| Seniority fit | 15 | Alignment with the user's experience level and the role's responsibility scope. |
| Compensation and preferences | 10 | Compensation evidence, company-stage fit (startup vs corporate), and other user preferences, when available. |
| Freshness and source confidence | 10 | Availability verification, posting-recency evidence, and source quality. |

## Handling unknowns

When a job description omits optional information (commonly compensation), identify it as
**unknown** rather than treating it as either a match or a rejection — unless the profile declares
that information mandatory, in which case the missing field is a must-have violation.

## Scoring discipline

- Award points only for evidence actually present on the source page, not assumptions.
- Record a short rationale per dimension when it materially affects the total.
- Two listings may tie; preserve the order produced by the rubric and note ties if relevant.
- A higher freshness/source-confidence score requires a successful availability check with a recent
  posting date or clear "active" signal.
